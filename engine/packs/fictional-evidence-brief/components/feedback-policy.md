# Fictional pack feedback policy

For a failed factual obligation, record a reproducible canonical
improvement *proposal* scoped to the owning phase, component or
summary skill. This proposal does not modify the public pack.

For a safe consumer request about report style, apply that choice
only in the current task. An opt-in future preference requires
specific consent and real user-private storage. This pack never
persists consumer values, telemetry or identity.

For a mixed finding, separate the canonical defect from the optional
style preference before testing either. Hold a request to skip evidence
checking or escalate host authority. Stop when there is no material
falsifying finding. Static self-review is not consumer validation.
