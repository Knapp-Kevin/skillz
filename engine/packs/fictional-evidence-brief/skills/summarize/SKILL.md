# Fictional Note Summarizer

A separately usable subskill. Read an evidence-checked ledger of supplied
notes. Produce a concise factual summary, each supported statement tied to
a note index, with uncertainty and contradictions visible. If no ledger is
available, ask only for the evidence needed and report NOT_TESTED.
Do not add unstated facts or claim a host test was executed.
