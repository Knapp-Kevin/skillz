# Project Concept

## Why (One Sentence)

A single governed reference point where all MythologIQ agents — local (COREFORGE), cloud (Claude Code, Qortara-adjacent), and everything between — discover, evaluate, and receive ungated cadence skills without duplicating Qor-logic's gated SDLC registry.

## Vibe (Three Keywords)

curated, portable, self-maintaining

## Boundaries

- **In scope**: ungated cadence skills (pulses, briefings, hygiene), the third-party intake registry, vendored official skill sources, the generated index, and the meta-tooling that validates and deploys all of the above.
- **Out of scope**: gated SDLC skills (Qor-logic owns those), skill *execution* infrastructure (hosts own that), community skill copies (registry entries only).

## Success Criteria

- Any agent can resolve a skill from `INDEX.md`/`index.json` and follow its SKILL.md unaided.
- Every third-party skill entering an agent's context has a registry decision behind it.
- The repo validates itself (`skill-audit`) and deploys itself (`skill-sync`) without manual bookkeeping.
