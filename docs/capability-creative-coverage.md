# Music and illustration: what we can actually help with

These are **14 different creative jobs**, not interchangeable styles or a count of GitHub folders. Some need musical theory, others need a production tool. Some need an art-direction brief; others need to draw a finished comic or scientific diagram.

The current **bounded reference shelf** contains **one method for music composition (timecoded scoring)** and **three for illustration (concept briefs, sequential panels and character consistency)**. All are **Valuable References**, meaning useful ideas to learn from, **not approved packages to install or run unchanged**. The remaining capabilities have discovery leads or no qualified method. We still need real alternatives and stronger coverage.

## What it would mean to close these gaps

We need useful, distinct and individually justified methods in **each** subdomain, meaningful alternatives where approaches differ, exact pinned evidence including package-tree and license/NOTICE where accessible, and a clear record of what's safe to do. The full upstream package-tree identity for the four newly reviewed methods remains **UNKNOWN**; a pinned SKILL.md is not proof of an entire package. That is a remaining identity gate, especially for unchanged use.

The new methods are [graded with ten individually justified dimensions](../registry/discovery/q6-four-package-static-reviews-20261103.json), with no package-security or behavioral execution claimed. [Read the practical benefits and warnings](reviews/2026-11-03-q6-four-method-static-review.md). [See the structured 14-subdomain map](../registry/discovery/q6-creative-capability-routing-20261103.json). The separate [#677](https://github.com/Knapp-Kevin/skillz/pull/677) research draft tracks four more source families without claiming qualification.

Its 0/8 and 1/6 are historical *review-or-candidate link coverage*, not the newly reviewed method count. Don't add different accounting stages together or claim the graph is now complete. Our global distinct eligible-skill denominator remains **UNKNOWN**.

**Where it goes next:** Resolve full package identities and source rights, then qualify larger music theory/arranging/notation batches and real environment, scientific and editorial art workflows. User-authorized tool execution is separate from recommending any skill.
