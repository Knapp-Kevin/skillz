## Differential scope and review rubric

Taxonomy Steward governs **canonical term meaning/version/alias conflicts** across authorized sources. File Lifecycle Curator classifies a bounded collection and may consume the approved taxonomy. Federated Source Catalog maintains source identities/permissions, not the taxonomy lifecycle.

Reference Integrity Auditor governs **dependency edge resolution, broken-link evidence, bounded orphan analysis and impact proposals**. Federated Catalog discovers and relates permitted sources but does not implement a separate reference health audit; this skill cannot claim exhaustive graph coverage from a source search window.
