**Why the gap stays open:** A generator prompt or an art-director checklist can teach framing, but neither demonstrates the end-to-end craft of sketching an original environment, establishing physical layout, perspective, compositional beats, environment props and material/lighting coherence, and validating gameplay/readability. Current character-only and photo-style methods also do not substitute for this.

**Static-only safety findings:** The first source requests broad `Bash(curl *)` and sends content to a remote model with an API key, including optional private reference images and batch calls. The second has missing root redistribution rights. The third orchestrates provider jobs, uploads and downloads with unresolved rights. **No source commands were executed; no tests/scans, paid requests, private data uploads, asset copies or new user-facing positive promotions.** These are research findings, not runtime exploit demonstrations.

**Next:** Search for at least one independent, licensed original environment-scene workflow; review art assets per file, qualify safety for any tool actions, then test perspective, navigation hierarchy and style consistency against concrete human-reviewed scenes before public endorsement.
