## Macro-first findings

It overlaps existing general engineering/UX, testing and security references, but the narrow SwiftUI scene ownership, AppKit bridge, notarization-versus-debug separation and macOS-specific window behavior are useful differentiated methods. No new first-party skill is justified merely by this plugin's existence.

**Shared dependency and exposure map.** `build-run-debug` is the operational hub. Its `references/run-button-bootstrap.md` is the canonical project-local script template, also invoked by `swiftui-patterns`, `liquid-glass`, `telemetry`, `window-management` and the plugin-level build command. The template uses `pkill -x`, `rm -rf` of the staged app bundle, `swift build`, `open -n`, optional `lldb` and `log stream`; the skill additionally prescribes `git init` and writing `.codex/environments/environment.toml`. **These are upstream reference procedures, not `skillz` runtime.** A project-specific app name is not authorization to kill processes, delete artifacts, initialize a repository or launch potentially sensitive code.

**Authority and privacy clusters.** Unscoped project writes, process termination, build/test execution and log streaming are recurring hard failures. `telemetry` contains a concrete `Logger` example that interpolates `item.id` as `privacy: .public`, despite general instructions not to log personal data. **Quality and omission defects.** The family has useful macOS 15+ API-specific guidance but lacks a common action-specific authorization gate for its active paths. The upstream run-button TOML template contains a literal `# THIS IS AUTOGENERATED. DO NOT EDIT MANUALLY` comment despite being prescribed as agent-created project content, an ownership/maintenance ambiguity. The plugin README's eleven names agree with the exact tree, so **no denominator omission** was found. Manifest MIT labeling without controlling terms is the material provenance defect. No scripts, CI, tests, preflight or other execution infrastructure are added to `skillz`.

**Priority decision.** This family is valuable as bounded reference knowledge but not an admission candidate under current terms/authority.
