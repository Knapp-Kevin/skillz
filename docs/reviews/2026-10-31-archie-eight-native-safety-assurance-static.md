## Synthesis: recurring hard failures and useful extraction

1. **False enforcement and evidence laundering:** `dangerous-action-guard/audit.py` records an action as executed on `--confirm` without checking the supplied phrase or matching command and without action evidence. `quality-gate-orchestrator/gate.py` accepts self-reported passes and required-gate waivers with only a note, then reports ready; empty gates are ready. `spend-circuit-breaker/check.py` advertises a hard cap and automatic cron pausing but only flips a local flag, while re-reading full modified session files can double-count historical spend. No such output is trustworthy release, financial or authorization evidence.
2. **Secrets and private-data retention:** `loop-circuit-breaker` retains raw argument/error prefixes; `prompt-injection-guard` retains unredacted external-content excerpts and source identifiers; `workspace-integrity-guardian` stores complete private identity/memory files as reversible base64. These are disclosure/retention risks, not harmless audit metadata. Regex absence is not proof that external instructions are safe.
3. **Unauthorized side effects:** `expansion-grant-guard` self-issues arbitrary scope grants without validating delegator authority, audience or resource identity, with cooperative rather than enforced budgets. `mcp-health-checker` launches configured stdio commands and sends HTTP probes using private MCP config and inherited environment, with an implicit six-hour cron. `workspace-integrity-guardian` assumes weekly private-file monitoring and offers destructive restoration. Neither tool access nor a grant ledger supplies user authorization.
4. **Source-family value and limits:** The package set offers differentiated patterns for bounded approvals, scoped delegation, retry classification, budget awareness, gate ledgers, injection triage, integrity baselines and MCP diagnostics. Adapt/extract the **methods** as advisory host-agent checklists only after independently supplying exact target/action permission, redaction, truthful evidence, safe retention and externally executed acceptance. Do not install, schedule, invoke or trust these unchanged. Script/STATE_SCHEMA discrepancies (JSON stored under .yaml, cooperative enforcement, unsupported hard-cap claims) lower operational portability and source-family priority for unchanged adoption.
