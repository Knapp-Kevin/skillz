six-file replacement, including the 17-profile JSON routing catalog,

correction handling, scope/authority boundaries and differentiated

explicitly require** each topic's distinct report sections.

Important examples:
- GitHub discovery: distinct newly created vs accelerating repository
  populations, specialization into AI/MCP/tooling, a maximum
  three-item deeper-look shortlist.

  changes vs conditional practical relevance.

  must not be buried under product news or reception.

  with drafts, standards changes or commentary.

  artifacts vs reproducible measurements must be distinct.

adds an explicit source-to-report routing requirement in SKILL.md,
and adds twelve negative/edge cases to the existing acceptance
specification. The shared evidence ledger and host safety boundaries
remain authoritative. The new contracts do **not** require showing
seventeen empty sections when only one profile was requested.
