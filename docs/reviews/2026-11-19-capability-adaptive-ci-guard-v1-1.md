# Universal capability-adaptive execution: adoption and CI Guard v1.1

2026-11-19 | Static source review. **Not** multi-model A/B.

The canonical [standard](../capability-adaptive-skill-execution.md)
is linked from the template, verification rubric, governance and
architecture indexes and navigation. It applies to all 30 current
authored packages and every future reviewed Skillz skill, including
external sources where selection/governance permits. It does not
change anyone's tool permissions or relicense third-party content.

The central rule is a single invariant for every model: same
authorized user outcome, safety, provenance, evidence and failure
honesty. The *assistance* adapts: direct execution when justified,
optional worked examples when a decision is uncertain, truthful
fallback at real capability or authority blockers. There is no
artificial per-model ceiling or mandatory workflow for its own sake.

**Existing-corpus limitation:** All 30 authored entrypoints were
read in a coarse structural screen, but were **not** behaviorally
validated across models. No mass edits, inferred certification,
new automated gate or arbitrary quality score changes. Re-evaluate
specific skills at material changes or verified failures.
