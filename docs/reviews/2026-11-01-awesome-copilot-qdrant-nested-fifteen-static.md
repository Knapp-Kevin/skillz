## Macro findings

1. **Authority hard failures dominate.** Thirteen procedures recommend reading private telemetry/logs or making live index, replica, node, shard, alerting, retention or ranking changes without a separately bounded authorization decision. A generic diagnostic or design request does not authorize production reads, cloud spend, persistent changes or recipient notification.
2. **Destructive retention is a standout risk.** `sliding-time-window` directly instructs deletion of shard keys, collections and points. It warns about checking the date window but does not require data-owner consent, legal-hold review, verified backup, dry run or recovery plan. Preserve the rotation comparison, reject unchanged execution.
3. **Sensitive-data and egress gaps.** Monitoring setup routes audit logs to aggregation systems and alerts to third parties; search-strategies suggests an external package and model integrations. None establishes exact recipients, credentials, query/payload sensitivity, retention, cost or transmission authority.
4. **Version/workload-sensitive assertions.** Fixed segment counts, 80% RAM heuristics, 95% recall targets, shard recommendations, zero-downtime claims and API-version-specific features are not portable guarantees. The source links to upstream documentation, but those live pages and runtime behavior were not independently checked in this static pass.
5. **Distinct useful methods remain.** Exact-vs-approximate retrieval diagnosis, resident-vs-cache memory accounting, optimizer-first triage, capacity strategy routing, hybrid/rerank/feedback selection and time-window rotation tradeoffs are reusable as evidence and design inspiration, subject to their rights and approval boundaries.
6. **Taxonomy omission.** The current 32-domain/240-subdomain capability directory has no dedicated database/vector-retrieval systems domain. The 15 reviewed identities are conservatively linked to existing backend, SRE, cloud architecture, privacy, measurement and cost-optimization subdomains. A new domain is not silently invented while capability-coverage #588 / draft #590 remain active.
7. **Public candidate-directory drift detected and repaired.** Main advertised 35 subdomain candidate examples but actually contained 15; its distinct source/path/pin candidate union was 25, not the stated 28. After this tranche, the actual directory arrays contain **30 subdomain examples**, **38 overview previews**, **40 distinct source/path/pin candidate identities**. Governed evidence-linked identities remain 78.
