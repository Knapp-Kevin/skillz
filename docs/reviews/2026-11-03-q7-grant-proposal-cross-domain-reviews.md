**What was verified:** Four complete, nontruncated pinned upstream Git trees; all six package Git tree identities and **42/42 owned file blob hashes** enumerated; **39 textual files actually inspected**, three spreadsheet binaries not opened or run. Source and per-package licenses/NOTICE checked. This is static evidence, not an executed security scan or working grant submission.

**Actual benefit for an agent:** A task to find funding should not stop because the featured 19 do not include a grant title. First map the user's work to the provisional nonprofit track and adjacent **research, planning, technical writing, finance, marketing, business and legal** areas. Then inspect these source-pinned candidates, current grant rules, data permissions and compatibility. An existing skill can be refined from a method, or a new original one authored with proper rights. Do not copy the commercial kit, protected evaluator quotes, raw financials or private organization data into a public index.

**Important distinction:** MIT for the three nonprofit methods and free Zicula edition does not cover external source documents or the separately sold kit. MIT for the research orchestrator does not grant consent for reading PI documents or executing tools. The EU method is CC BY-ND, so share only independently authored high-level conceptual summaries here; do not reproduce protected methods or quotes.

**Disposition:** Five static **REFERENCE-ONLY / study-method** candidates, one **REJECT unchanged** due to authority/dependency risk. No approved installations, no user-specific fit test, no security scanner, no actual grant proposal produced, no featured Valuable Reference promotion, and no clean independent first-visitor agent test. The featured shelf remains **19 across nine canonical domains** while the provisional domain accumulates evidence.
