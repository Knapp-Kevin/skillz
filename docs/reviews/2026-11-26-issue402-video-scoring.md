## Findings (11/20 static)

- **uncontained-output-paths-and-overwrites (HIGH)**: scripts/score_cue.py cmd_render, compose, post_process; SKILL.md render example. The JSON name is interpolated into MIDI, raw/final WAV and report paths without a basename or containment check. Absolute or parent-relative names can escape outdir; existing files and symlink targets are not protected. MIDI save, ffmpeg forced replacement and report write can replace existing content, including before a later validation failure. Require safe leaf names, bounded fresh workspace, no-follow/exclusive output handling and explicit replacement permission.
- **filter-language-and-resource-authority (HIGH)**: scripts/score_cue.py post_process, load_channels, cmd_render. Untrusted JSON values are inserted directly into FFmpeg filtergraph expressions, including a freeform loudnorm string and fade fields. Argument arrays avoid shell interpolation but do not prevent filter-language injection. Unrestricted input paths and whole decoded audio buffering plus missing numeric/resource limits also weaken isolation. Use typed validated fields, fixed filter graph, approved local files, explicit stream selection, bounded decoding and time/resource limits.
- **storyboard-fail-open (MEDIUM)**: scripts/score_cue.py measure, cmd_render, cmd_measure. The inclusive median comparisons accept both quiet and loud checks at the same constant level, including silence; out-of-range timecodes are matched to the nearest existing window; unknown expectations are not failed. cmd_measure exits nonzero only for clipping, not failed storyboard checks. Enforce positive dynamic margins, valid ranges and labels, nonempty finite audio, and consistent failure status.
- **measurement-and-variant-claim-ceiling (MEDIUM)**: SKILL.md measurement and variants; scripts/score_cue.py load_channels, measure, cmd_fingerprint. Sample peak does not certify true peak or loudness, mean downmix can cancel opposing channels, and the probe selects first audio stream but decoding does not explicitly map it. Distinct rounded duration/peak/centroid tuples prove only those metrics differ, not the intended instrument or arrangement; identical tuples do not prove byte identity. Bind comparisons to changed parameters, decoded signal identity and target metrics.
- **provider-egress-cost-and-filter-boundaries (MEDIUM)**: SKILL.md Route B and Secrets; historical E1 MEDIUM line 171. The documented API sends prompts externally with an API key; the source recommends rephrasing after a copyright filter and makes broad provider architecture, timing and licensing claims from limited dated observations. Do not retry to defeat safeguards, infer universal model behavior, or send private prompts, spend quota or access credentials without separate authorization. Historical documented-egress finding remains unchanged and unaccepted.
- **asset-identity-and-standalone-dependency (MEDIUM)**: SKILL.md Toolchain, Soundfonts, helper script; root LICENSE; earlier issue #402 rights note. The single owned file refers to root-level score_cue.py, which exists at the pin outside the scanner package, and unpinned local tools/packages and a remote soundfont. Prior issue evidence corroborates the MuseScore General family-level MIT statement, but exact hosted binary digest/notice and applicable rendered-output terms remain unresolved. - **overclaimed-audio-normalization-and-timing (MEDIUM)**: SKILL.md Route A, music under voice-over. A MIDI event schedule does not guarantee exact audible onset or envelope after synthesis. FFmpeg linear normalization can fall back to dynamic behavior; the instruction does not require verifying normalization_type. Verify actual mode, true peak, integrated loudness and timing against the delivery contract; retain human listening acceptance.
