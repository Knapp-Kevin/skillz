## Material licensing concerns

- **Scientific illustration, coordinated with PR #677:** The referenced `WuyangFF95/CC_icons` pipeline describes a multi-source "CC0" asset library. That description is not blanket clearance. [Servier Medical Art itself specifies CC BY 4.0](https://smart.servier.com/smart_image/slide/) and requires attribution; [NIH BioArt says licenses and attribution vary by item](https://bioart.niaid.nih.gov/faqs). Verify each acquired icon's source, license and citation before any library use, mirroring, distribution or publication.
- **LilyPond Score Editor and Editorial Line System:** Both root LICENSE fetches returned 404 at their pinned source revisions. These are leads for reading and independently summarizing ideas only, not licensed source code or installable-package endorsements.
- **Music books and examples:** A root MIT license for an agent workflow does not relicense textbook prose, musical works, lyrics, sample libraries or recordings it describes.
- **External models and persistence:** ElevenLabs and Scenario workflows involve accounts, model calls, costs, private uploads and possibly storage. None of those actions was authorized or attempted.
