## Function crosswalk and stronger effective-permission reasoning

The original essential workflow reviewed a specifically approved agent/workspace's MCP tools, host allowlists, hooks, credential *classes* (not values), last-use metadata, high-consequence permissions and proposed tightenings, while prohibiting any automatic edits or a recurring audit absent separate approval. The replacement expressly retains all those obligations: complete manifest tool inventory; read-only/generate-only/mutating/external-side-effect classification; host-enforced execution restrictions; refusal of unsafe `Bash(git *)` wildcard; scoped tool API alternatives; last-used UNKNOWN without revocation assumptions; privacy and secret redaction; report-only default; optional periodic review only with separate explicit authorization. It adds principal→action→resource and delegated composite-path checks, conditional approval boundaries and post-change rollback/verification plans. This is **source-level design consistency**, not an actual 1.5x effectiveness demonstration.
