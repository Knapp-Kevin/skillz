## Systemic synthesis and omission findings

1. **Exact identity defeats catalog inflation.** Nine plugin exposures do not add nine admitted skills. Six overlap an already governed source, two at identical manifest blobs but divergent package trees. Reusing prior approvals based on names or manifest identity alone would be incorrect.
2. **Authorization failures are structural.** Deployment, durable storage, cron, mail, arbitrary SQL, secret handling, browser traces, live logs and cloud resource deletion recur across the family. Host tool availability and input confirmation are not user authorization.
3. **Privacy and money-bearing boundaries matter together.** Agent message persistence and broadcast, Workers AI inference, Cloudflare logging, email reply and Sandbox preview DNS each have a separate disclosure, retention, billing or resource impact.
4. **License scopes conflict.** Parent plugin MIT label and three child Apache-2.0 license texts do not justify blanket MIT copying. Keep source references linked and no vendoring.
5. **README omission:** the pinned Cloudflare plugin README enumerates eight skills, but nine direct manifests exist; `workers-best-practices` is omitted. Tree enumeration controls the denominator.
6. **Admitted-source correction prompted by comparison:** registered `cloudflare-skills/agents-sdk` at a **different** exact pinned package contains `npm install`, persistent state/scheduling, identity-bearing logs and a bundled email reference with automatic replies. Its prior `VERIFIED 17/20` unchanged-use approval does not satisfy the current action-specific authorization hard fail. A separate exact-pin correction is recorded in its existing provenance/verification companions: **REJECT unchanged 14/20**, behavioral `not-run`, source 13/13 static completeness preserved. The previous record remains in Git history; the current record is decisive. This does not alter the upstream pinned bytes.
7. **No behavioral evidence fabricated:** no plugin installed, browser navigated, Cloudflare account queried, MCP tool invoked, secret entered, cloud resource changed, scanner run, or agent executed. Source-owned tooling remains upstream evidence.
