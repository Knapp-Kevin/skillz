## Differentiation

Nearby first-party methods already exist. Agent Failure Boundary Analysis
is read-only incident investigation; Skill Trial Evidence Auditor
adjudicates paired agent-behavior evidence; Repository Delivery Assessor
assesses project delivery. None performs bounded source correction plus
negative and preservation checks across arbitrary user artifacts.
This new skill explicitly owns the improvement workflow while respecting
specialized verification and authority boundaries.

## Scenarios interpreted

The ten synthetic cases challenge real-root README correction,
irrelevant search matches, CI classification false skips, report-only
nonprogress, appropriate no-change, unauthorized writes, inherited
historical test successes, infinite polish, constrained host operation,
and a speed improvement that breaks permissions. They are **design
cases**, not outcomes observed in an independent model host.

All four files were read at the exact package revision. Thirteen
read-only source-contract checks identified the mandatory trigger,
correction, counterexample, regressions, stop and authority semantics.
All eight local Markdown references resolve within the package.
No runtime commands, external calls, consumer edits, automated Python
tests, image-generation actions, deployments or GitHub Actions were run.
