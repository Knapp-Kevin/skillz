## Macro findings, omission check and recommendation

1. **Privacy/telemetry omission:** `brainstorming/scripts/server.cjs` defaults to an HTML image URL at `https://primeradiant.com/brand/superpowers-visual-brainstorming-logo.png?v=<version>` unless a telemetry-disable environment variable is set. Even with `referrerpolicy=no-referrer`, loading that image may disclose client network metadata and plugin version to a third party. The visual companion requires user approval to start, but the external image request is not separately explained or scoped. This is an **unchanged-use authority hard fail**. No server was started and no request was made in this review.
2. **Secret disclosure:** `systematic-debugging` includes an example `env | grep IDENTITY`, which can print credential-bearing environment values to logs. Extract the component-boundary hypothesis method, not the raw environment logging instruction.
3. **Unapproved installs/destruction:** `using-git-worktrees` automatically invokes package managers; `test-driven-development` commands deletion of pre-existing implementation. Neither action is made safe by generic task intent. Adapt only with explicit destination, dependency/network, preservation and rollback authority.
4. **Delegation is not permission:** `dispatching-parallel-agents`, `requesting-code-review` and `subagent-driven-development` assume code/context can be shared with other agents and tasks can be committed continuously. A well-written prompt does not establish recipient/data-sharing, spend or persistent-write authority.
5. **Strong methods worth retaining:** fresh evidence before claiming completion; technically skeptical review reception; branch-finish choice and no-force-delete guard; interface-complete plans; task-scoped review gates. These support **REFERENCE-ONLY / EXTRACT / ADAPT** decisions by a future authorized host, not automatic installation or corpus admission.
6. **Source priority:** finite candidate slice exhausted **14/14**. No known unreviewed first-class package remains in this plugin at the pinned mirror snapshot. Other plugin families remain discovery leads, not admitted denominators. The higher-priority first-party repair frontier remains **36** changed package trees requiring independent external qualification.
