# First-Run Experience Validator

Original, MIT-licensed, standalone and offline-capable authored skill.

**Job:** determine whether someone new to a product can actually go
from published install/getting-started instructions to one meaningful,
observed working outcome, in a controlled fresh environment.

Start with [SKILL.md](SKILL.md). Copy the full directory into an
authorized skill host. Use [templates/evidence-ledger.md](templates/evidence-ledger.md)
to record one journey per persona/platform, and
[examples/acceptance.md](examples/acceptance.md) to challenge false
claims with 20 entirely fictional cases. No script, runtime, network,
GitHub account, external verifier, sibling skill or project checkout
is required for the method itself.

The skill performs **analysis**, not automatic installation or
recruitment. A real clean-host run is only a valid observation if a
separately authorized capable host actually conducts it and records
the exact environment and first-task proof. This package contains
**no observed consumer-host validation** or claimed installation
success. The first publication is v0.1.0, with static review and
independent behavior qualified separately.
