# Sandler-aligned Conversation Strategist: version history

This is the first-party **independent** package history, not an official
Sandler training, course or certification record. The repository's source
identities (Git blob and complete package tree) remain the authoritative
exact-code/content fingerprints. No external consumer installation is
asserted from this file.

## 0.2.0: buyer-controlled branching and interactive rehearsal (2026-11-24)

**Minor capability release** relative to the original `0.1.0` reference:
- Introduced buyer-signal decision branches including no-contact holds,
  limited discovery, proposal hold, no-fit and buyer-consented proposals.
- Strengthened source-provenance, conflict/revocation and explicit
  Sandler-to-MEDDPICC evidence-state translation.
- Added dimensionally safe, period-bound illustrative training value
  calculations, still not measured ROI.
- Added **turn-by-turn optional fictional role-play**, one buyer turn
  at a time, with source-linked, buyer-respectful coaching and an
  explicit stop/continue choice. No rep turns or buyer history are
  fabricated or automatically persisted.
- Added false-success and adversarial examples as independent portable
  supports.

**Compatibility and safety:** This adds optional behaviors without
changing the activation or read-only/default-no-contact authority
ceiling. A host using `0.1.0` assumptions should re-read the complete
`0.2.0` package before claiming equivalence; mixed-version handoffs
retain evidence state but require explicit counterpart confirmation.
The release version does not certify host behavioral validation.

**Why minor, not patch:** New user-observable conversation routing,
interoperability and practice capabilities, accumulated across the
merged first-party revisions, were more substantial than wording and
correction-only changes. Prior source updates left `0.1.0` unchanged
too long. This single minor increment **consolidates** those changes,
rather than incrementing for each Git commit or PR.
