# Repository README Architect

An original, portable Skillz skill for **creating a README from scratch**, uplifting an existing one, auditing its reader experience, or verifying it against the actual repository.

The output is a concrete Markdown artifact or an authorized focused PR, not a generic template or list of recommendations. The procedure adapts to libraries, CLIs, apps, frameworks, datasets, research code and empty repositories. Its default narrative is problem → product → method → proof → action, but clarity and the target audience decide the actual ordering.

**Start:** [SKILL.md](SKILL.md). The full execution contract is included there; no other files are required. [Acceptance scenarios](examples/controlled-scenarios.md) are optional test fixtures, not live behavioral validation.

**Status:** original MIT-authored v0.1.0. Exact-version static qualification and external agent behavioral effectiveness are separate; do not infer either from package presence.

**Authority:** inspection is read-only by default; creating or changing a repository file requires the user's bounded instruction and available host permissions. No blind command execution or automatic deployment.
