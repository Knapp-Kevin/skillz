# Character Motivation Interview

Independently authored [MIT](LICENSE)-licensed workflow for structured fictional-character development. The [SKILL.md](SKILL.md) instructs an agent to ask concise questions, distinguish canon from options, connect choices to scenes, and produce a copy-ready character card without writing to a project. [Invented acceptance scenarios](examples/acceptance-cases.md) specify expected and prohibited behavior.

This skill does not store state, log in to a service, recreate a visual wheel interface, diagnose real people, or grant access to private project files. Host-model behavior has **not** been executed or qualified.

General inspiration comes from a separate publicly described, all-rights-reserved character-development tool. Its app, content, code and data are not part of this standalone original package.
