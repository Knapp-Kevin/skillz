# MEDDPICC Opportunity Assurance: version history

First-party **independent** evidence-review skill, not an official
MEDDPICC vendor course, certification or buyer forecast model. Git
blob and complete package-tree identities distinguish exact source
revisions; this document is not evidence of installation or host use.

## 0.2.0: action-specific opportunity gates and hold recovery (2026-11-24)

**Minor capability release** relative to the initial `0.1.0` reference:
- Separate evidence `REVIEWABLE` from concrete proposal, forecast,
  signature, contract execution and delivery readiness.
- Add evidence state/provenance and Sandler cross-method translation
  without automatically verifying copied seller quotes.
- Preserve explicit current-access precedence, differing buyer
  contradiction and seller disconfirmation, stale-source handling.
- Add **evidence-gated HOLD recovery**: an actually authorized new
  source can close only the exact missing buyer-owned obligation;
  all other blockers must remain visible. A supported readiness
  decision never means authority to send, forecast, sign or mutate.
- Add regression cases for partially cleared and properly cleared
  gates, unrelated source substitution and revoked viewer permission.

**Compatibility and safety:** The standalone package remains
read-only by default and does not require a live CRM, Sandler
skill, script interpreter or connection. Mixed-version handoffs
must keep original source/provenance states and should not assume
that older consumers understand the new conditional gate labels.
No automatic close probability, vendor affiliation or production
buyer behavior is claimed.

**Why minor, not patch:** Commercial readiness gating and reversible
evidence-based action state transitions are material new user-facing
capabilities. This release consolidates earlier merged capability
extensions that were conservatively left at `0.1.0`. It is not an
increment for each small document correction.

## 0.1.0: initial independent reference (2026-11-24)

Original eight-factor MEDDPICC opportunity evidence ledger, source
distinctions, stakeholder/process and paper analysis, safe
disconfirmation and forecast uncertainty. Later source-level
revisions strengthened the procedure without issuing separate
semantic release numbers; their exact hashes remain historical,
not evidence of separate externally deployed artifacts.

The public repository's review documents give historical static
qualification context; they are not runtime dependencies.
