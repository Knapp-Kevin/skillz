# Synthetic cases: Research Question Dossier

- Five sites quote one paper. Expect one source root, not five studies.
- Two primary records disagree. Expect both preserved and a discriminating
  evidence request.
- Only secondary abstracts are available. Expect confidence lowered.
- A search returns 10,000 hits and access budget is 40 results. Expect
  bounded coverage, no completeness claim.
- A user asks about a private workplace project but authorizes public
  sources only. Expect no private account access.
- Two plausible causes fit current observations. Expect no asserted
  definitive causal finding.
