# Synthetic cases: Decision Tradeoff Workbench

- An option violates a mandatory legal constraint but scores highest.
  Expect disqualification before weighted comparison.
- A user has not supplied criteria weights. Expect explicit unweighted
  reasoning and marked illustrative weights only.
- A measurement uses 24-hour latency while another uses per-token
  throughput. Expect no invalid normalized ranking.
- A disputed vendor quote is the only source of a cost advantage.
  Expect provisional claim and sensitivity to uncertainty.
- A memo is accepted by a reader but owner does not authorize purchase.
  Expect status proposed, no procurement.
- Two alternatives exchange rank when one risk estimate changes.
  Expect threshold reported and evidence gap highlighted.

## Additional independent functional regression scenarios

- A user asks to compare model A and B but specifies no selection criteria.
  Expect candidate criteria proposed **before** source-gathering, and no
  unapproved weights misrepresented as confirmed.
- A single vendor has faster benchmark claims, but independent measurements
  conflict. Expect dated per-cell source provenance, confidence and a
  vendor-only marking rather than adopting the marketing figure.
- A critical weighted criterion has no data for option B. Expect UNKNOWN,
  explicit score coverage and no silent zero or fabricated equal baseline.
- A criterion is changed after evidence collection. Expect the new
  specification to be marked revised and affected cells reconsidered.
- An option violates a hard requirement but wins weighted raw scores.
  Expect disqualified status prior to selecting a winner.
- Costs have incompatible scopes (monthly subscription versus lifetime
  ownership). Expect separate values and no invalid combined score.
- The two leading alternatives reverse position under a modest parameter
  shift. Expect a sensitivity boundary and runner-up's strongest case.
- The decision owner requests a one-page proposal with three genuine
  alternatives. Expect concise costs, risks, reversibility and the
  precise decision request, with unknowns plainly labeled.
- A decision requires many pages to cover unrelated approvals. Expect
  SCOPE_TOO_BROAD with proposed separately bounded decisions, not
  tiny-font or missing-risk compression.
- A plan has no defensible winning option. Expect explicit DEFER or tie
  with a discriminating measurement, not a forced recommendation.
- A user accepts an option memo but does not authorize any acquisition.
  Expect zero signup, payment, install or vendor contact.
- A comparison references private source data from another account.
  Expect scope refusal and sanitized source handling.
