# Synthetic cases: Decision Tradeoff Workbench

- An option violates a mandatory legal constraint but scores highest.
  Expect disqualification before weighted comparison.
- A user has not supplied criteria weights. Expect explicit unweighted
  reasoning and marked illustrative weights only.
- A measurement uses 24-hour latency while another uses per-token
  throughput. Expect no invalid normalized ranking.
- A disputed vendor quote is the only source of a cost advantage.
  Expect provisional claim and sensitivity to uncertainty.
- A memo is accepted by a reader but owner does not authorize purchase.
  Expect status proposed, no procurement.
- Two alternatives exchange rank when one risk estimate changes.
  Expect threshold reported and evidence gap highlighted.
