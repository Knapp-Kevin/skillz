# Writing & Communication

Skills for turning evidence and decisions into clear human-facing artifacts.

- [`brief-writer`](../../brief-writer/) — write a one-page decision brief.
- [`deck-outline`](../../deck-outline/) — build a narrative-first presentation outline.
- [`devlog-draft`](../../devlog-draft/) — draft an evidence-backed founder or development log.
- [Context Continuation Contract](../../authored/context-continuation-contract/SKILL.md) — produce a verified zero-context handoff and optional separately authorized continuity (replaces `handoff-writer`).
- [Work Period Evidence Reporter](../../authored/work-period-evidence-reporter/SKILL.md) — evidence-backed Did / Doing / Blocked / Needs confirmation standup (replaces `standup-writer`).
