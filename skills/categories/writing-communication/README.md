# Writing & Communication

Skills for turning evidence and decisions into clear human-facing artifacts.

- [`brief-writer`](../../brief-writer/) — write a one-page decision brief.
- [`deck-outline`](../../deck-outline/) — build a narrative-first presentation outline.
- [`devlog-draft`](../../devlog-draft/) — draft an evidence-backed founder or development log.
- [`handoff-writer`](../../handoff-writer/) — preserve continuation context across sessions or agents.
- [`standup-writer`](../../standup-writer/) — generate evidence-backed standup or worklog updates.
