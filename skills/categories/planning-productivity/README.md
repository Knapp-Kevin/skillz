# Planning & Productivity

Skills for organizing work, making decisions, coordinating responsibilities, and reviewing progress.

- [`daily-briefing`](../../daily-briefing/) — build an action-first morning brief.
- [Decision Record Steward](../../authored/decision-record-steward/SKILL.md) — capture and revisit durable decisions with owner authorization and readback (replaces `decision-log`).
- [`inbox-triage`](../../inbox-triage/) — classify inbox work and draft replies without sending.
- [Learning Evidence Progression](../../authored/learning-evidence-progression/SKILL.md) — verifiable sources, applied checkpoints and missed-week recovery (replaces historical `learning-plan`).
- [`task-surface`](../../task-surface/) — coordinate responsibilities scattered across repos and systems.
- [Work Period Evidence Reporter](../../authored/work-period-evidence-reporter/SKILL.md) — evidence-backed Shipped / Stalled / Decisions / Monday Carry-forward review (replaces `week-in-review`).

Related repository-maintenance work such as TODO harvesting lives under [Software & Repositories](../software-repositories/).
