# Software & Repositories

Skills for maintaining repositories and turning repository state into actionable work.

- [Source Debt Triage](../../authored/source-debt-triage/SKILL.md) — evaluate maintenance comments against current code, coverage limits and risk. The historical `todo-harvester` source is retained only in immutable Git history.

For ecosystem-level GitHub scanning rather than maintenance of your own repositories, see [Monitoring & Intelligence](../monitoring-intelligence/).

Use [Repository Delivery Assessor](../../authored/repository-delivery-assessor/SKILL.md) for one-repository diagnostics and approved multi-repo attention reports. Historical [Repo Doctor](https://github.com/Knapp-Kevin/skillz/tree/ccd98e2a281939ac2820407a636c8bb698ec98d2/skills/repo-doctor) and [Repo Pulse](https://github.com/Knapp-Kevin/skillz/tree/ccd98e2a281939ac2820407a636c8bb698ec98d2/skills/repo-pulse) remain pinned in Git for source evidence only.
