# Software & Repositories

Skills for maintaining repositories and turning repository state into actionable work.

- [`repo-doctor`](../../repo-doctor/) — run a focused health check on a repository.
- [`repo-pulse`](../../repo-pulse/) — produce a recurring cross-repository work digest.
- [`todo-harvester`](../../todo-harvester/) — sweep TODO/FIXME/HACK/XXX comments into a triaged maintenance list.

For ecosystem-level GitHub scanning rather than maintenance of your own repositories, see [Monitoring & Intelligence](../monitoring-intelligence/).
