# File & Information Management

Inventory, describe, index, keyword-tag, organize, retrieve and archive approved file collections with recoverability and privacy in mind.

- [File Lifecycle Curator](../../authored/file-lifecycle-curator/SKILL.md) — original, portable first-party pack: scoped file inventory, summaries, source-aware indexing, normalized tags, metadata decks, deduplication/versions, reversible organization proposals and archive/retention review.
- [Portable metadata schema](../../authored/file-lifecycle-curator/references/metadata-contract.md) and [archive/operation safety rules](../../authored/file-lifecycle-curator/references/operation-and-archive-rules.md).
- [Exact-package static review](../../../docs/reviews/2026-11-18-file-lifecycle-curator-static-review.md): 18/20; external behavioral validation **not-run**.
- [Proposed file-management domain and 10 subdomains](../../../registry/discovery/file-information-management-domain-proposal-20261118.json). This proposal is **not yet canonical taxonomy coverage**.

The skill is read-only by default. Persistent indexes, file moves, archives, permission changes, deletion and third-party egress require separately scoped user/host authorization. Discoverability is not permission.
