# Browse Local Skills by Purpose

These folders are the human navigation layer for the locally maintained portion of the `skillz` library.

The canonical skill directories remain directly under [`skills/`](../) during the compatibility transition. That keeps existing index, audit, and install paths stable while recursive category-aware discovery is being integrated. The categories below are intended to become the canonical physical layout after that migration is verified.

## Categories

| Category | What it helps with |
|---|---|
| [Planning & Productivity](planning-productivity/) | Daily work, decisions, task coordination, learning, and reviews |
| [Writing & Communication](writing-communication/) | Briefs, decks, handoffs, standups, and devlogs |
| [Research & Analysis](research-analysis/) | Comparisons, deep research, fact checking, and paper review |
| [Software & Repositories](software-repositories/) | Repository health, repo monitoring, and codebase maintenance |
| [Agent Operations & Security](agent-operations-security/) | Agent environment health, postmortems, MCP vetting, and permissions |
| [Monitoring & Intelligence](monitoring-intelligence/) | Recurring ecosystem, model, protocol, governance, and platform scans |
| [Business & Career](business-career/) | Career scanning, finance review, and small-business operations |

For the complete library, including approved indexed third-party sources, use the root [`INDEX.md`](../../INDEX.md). Availability and quality are separate; consult [`CURATED.md`](../../CURATED.md) and [`registry/verification/`](../../registry/verification/) before treating third-party skills as trusted unchanged material.
